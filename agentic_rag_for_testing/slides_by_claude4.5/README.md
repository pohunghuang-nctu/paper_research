## 📂 檔案結構

```
slides_by_claude4.5/
├── index.html                    # 導航頁面（起始頁）
├── style.css                     # 共用樣式表
├── slide_01_by_claude4.5.html   # 封面
├── slide_02_by_claude4.5.html   # 核心重點摘要
├── slide_03_by_claude4.5.html   # 實驗結果對比
```

## 🚀 使用方式

### 方法一：直接開啟（推薦）
1. 用瀏覽器開啟 `index.html`
2. 點擊「開始簡報」或選擇任一投影片

### 方法二：從第一張開始
直接開啟 `slide_01_by_claude4.5.html`

## ⌨️ 導航方式

- **滑鼠點擊：** 使用頁面右下角的 ◀ ▶ 按鈕
- **鍵盤快捷鍵：** 
  - `←` 左箭頭 = 上一張
  - `→` 右箭頭 = 下一張
- **返回首頁：** 點擊左上角的 🏠 按鈕

## 📊 投影片內容

| # | 標題 | 重點內容 |

| 1 | 封面 | 論文標題、報告人、日期 |

## ✏️ 修改投影片

每張投影片都是獨立的 HTML 文件，可以單獨編輯：

1. 用文字編輯器開啟想修改的 `slide_XX_by_claude4.5.html`
2. 修改 `<div class="slide-container">` 內的內容
3. 儲存後重新整理瀏覽器即可看到變更

### 修改樣式
編輯 `style.css` 可以調整：
- 顏色配置
- 字體大小
- 卡片樣式
- 動畫效果

## 🎨 設計特點

- **響應式設計：** 自動適應不同螢幕尺寸
- **漸變背景：** 現代感的紫色漸變
- **卡片式布局：** 清晰的資訊層次
- **動畫效果：** 平滑的過場動畫
- **易於導航：** 多種導航方式

## 🖨️ 列印或匯出 PDF

1. 在瀏覽器中開啟任一投影片
2. 按 `Ctrl+P` (Windows) 或 `Cmd+P` (Mac)
3. 選擇「另存為 PDF」
4. 重複步驟 1-3 列印所有投影片

## 📝 注意事項

- 需要架構圖 `agentic_rag_for_tesrting_system.png` 在上層目錄
