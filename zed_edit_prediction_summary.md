# Zed's Edit Prediction: A Deep Dive

**Powered by Zeta, a New Open-Source Model**

*A summary based on the official Zed blog post.*

---

## What is Edit Prediction?

- A feature that anticipates a developer's next move, going beyond simple code completion.
- Predicts and applies entire edits with a single press of the `Tab` key.
- Allows for a chain of follow-up edits by repeatedly pressing `Tab`.
- **Goal**: To create a seamless and intuitive coding flow where the editor feels like it's reading your mind.

---

## The Core Idea: Editing by Rewriting

- **Problem**: Traditional "Fill-in-the-middle" (FIM) models are not ideal for predicting complex edits at arbitrary locations in the code.
- **Zed's Solution**: Instead of filling a blank, the model **rewrites a snippet of text** around the cursor.
- **Advantage**: This approach allows the model to perform more powerful, multi-location edits, such as adding, deleting, and modifying multiple lines at once.

---

## Introducing Zeta: The Open-Source Model

- **Base Model**: Derived from `Qwen2.5-Coder-7B`.
- **Fully Open**: Zeta is completely open-source, which includes:
  - The fine-tuned model weights.
  - The dataset used for training.
- **Community Driven**: Zed encourages the community to contribute to the open dataset to help improve Zeta for everyone.

---

## The Training Journey

1.  **Innovative Evaluation**: Instead of brittle unit tests, Zed used a larger LLM (Claude) to check if Zeta's output matched assertions written in plain English. This robustly validates the *intent* of the edit.

2.  **Supervised Fine-Tuning (SFT)**: Started with a small set of synthetic examples generated by Claude, then bootstrapped with real-world usage data from the Zed team.

3.  **Direct Preference Optimization (DPO)**: To handle tricky edge cases, DPO was used. The model was trained on both positive (good edits) and negative (bad edits) examples to learn the nuances of helpful vs. problematic suggestions.

---

## Engineering for Speed: Minimizing Latency

- **Aggressive Goal**: Deliver predictions in under 200ms (p50) and 500ms (p90).
- **Key Techniques**:
  - **Speculative Decoding**: Since the rewritten output is often similar to the input, the model uses the input as a reference to parallelize token generation, significantly boosting speed.
  - **Optimized Serving**: Partnered with Baseten for high-performance model serving and deployed GPUs in multiple regions (North America, Europe) to reduce network transit time.

---

## Key Takeaways

- **Beyond Completion**: Edit Prediction represents a shift from simple code completion to a more powerful, predictive, and multi-step editing paradigm.
- **Openness as a Strategy**: Open-sourcing both the model and the data builds community trust and creates a flywheel for continuous improvement.
- **Pragmatic & Innovative Engineering**: The project showcases clever solutions to complex problems, from LLM evaluation to latency optimization, providing a blueprint for building production-ready AI features.
